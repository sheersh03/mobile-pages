Privacy Policy

Last updated: 19 November 2026

"Sheersh Gmail MCP" is a personal automation tool used only by its owner, Sheersh Atrishi. It is not offered to the public.

What it accesses

With the owner's permission, the tool reads, drafts and sends email in the owner's own Gmail account and reads and updates the owner's own Google Sheets.

How data is used and stored

  • Data is used only to run the owner's own email and spreadsheet tasks.
  • Sign-in tokens and data are stored only on the owner's computer.
  • No data is sold, shared with third parties, or used for advertising.
  • Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
